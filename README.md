# Qalinraac Academy

Enterprise LMS monorepo (`apps/api`, `apps/web`, `packages/shared`).

## Brand

- Primary: Deep Navy `#002B5C`
- Secondary: Vivid Lime `#70C100`
- Background: White `#FFFFFF`


```bash
pnpm --filter @qalinraac/shared build
pnpm --filter @qalinraac/api dev
pnpm --filter @qalinraac/web dev
```

Open http://localhost:3000/login

Instructor first login shows a blocking onboarding modal.
